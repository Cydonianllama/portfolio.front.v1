Hay varios conceptos que muchos desarrolladores experimentados usan para reducir trabajo repetitivo:

Scaffolding: generar módulos completos (Hygen, Plop, Angular CLI, Nest CLI, etc.).
Scratch files: archivos temporales para experimentar sin preocuparte por la arquitectura.
Boilerplate: una base reutilizable de un proyecto o módulo.
Snippets: pequeños atajos del editor para insertar código repetitivo.
Code Generation: generar código a partir de plantillas o incluso de un esquema (por ejemplo, OpenAPI → cliente TypeScript).
Convention over Configuration: definir convenciones para no tener que configurar todo cada vez. Rails y Next.js son ejemplos clásicos.
Cookbook o Playbook: un repositorio personal de soluciones frecuentes ("cómo hago autenticación", "cómo creo un CRUD", etc.).
ADR (Architecture Decision Records): documentos muy cortos donde anotas por qué tomaste una decisión arquitectónica. Son muy útiles cuando el proyecto crece.
Golden Path: una forma "oficial" de hacer las cosas en el proyecto. Si alguien crea un módulo, siempre sigue el mismo camino.
Template Repository: tener un proyecto base ya configurado (ESLint, Prettier, Docker, CI, etc.) para no empezar desde cero.
